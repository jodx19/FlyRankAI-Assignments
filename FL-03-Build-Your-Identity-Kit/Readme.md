## 🎨 2. Color Palette (Hex Codes)

```text
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│ Primary / Accent│ │ Near-Black Text │ │ Off-White BG    │ │ Subtle Border   │
│     #0D9488     │ │     #0F172A     │ │     #F8FAFC     │ │     #E2E8F0     │
└─────────────────┘ └─────────────────┘ └─────────────────┘ └─────────────────┘
```

- **Primary Accent Color:** `#0D9488` _(Teal 600 - Represents precision, technical reliability, and modern logic)_
- **Near-Black Text:** `#0F172A` _(Slate 900 - Soft contrast readable text for long architecture documentations)_
- **Near-White Background:** `#F8FAFC` _(Slate 50 - High-legibility workspace)_
- **Subtle Border / Muted:** `#E2E8F0` _(Slate 200 - Clean structural section divisions)_

## 📝 4. Two-Line Style Note

> _"The design system prioritizes absolute typographic clarity and minimalist dark-slate structural accents over ornamental decoration._
> _It lets complex architecture diagrams, benchmark numbers, and backend logic speak for themselves in a clean, high-contrast engineering environment."_
