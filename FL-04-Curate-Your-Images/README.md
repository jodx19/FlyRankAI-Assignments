## ⚖️ Curation & Rejection Analysis (Discernment Log)

### 1️⃣ Real Captures vs. AI Stand-ins

> **Decision:** Used real screenshots of C# code, Git logs, and xUnit execution terminals instead of AI-generated code snippets.
>
> **Why:** AI-generated "code images" often contain syntax errors, bizarre variable names, or non-existent framework APIs upon close inspection. Authentic captures act as verifiable proof of technical capability.

---

### 2️⃣ Rejection Note 1: AI Generated Developer Banner

- **Prompt Used:** _"Futuristic glowing cybernetic server room with 3D C# logos and floating neon code lines, dramatic lighting"_
- **Status:** ❌ **REJECTED**
- **Why it was rejected:** The output was overly dramatic, cluttered, and looked like a sci-fi video game. It completely contradicted our **FL-03 Identity Kit** principle (_"prioritizes absolute clarity and minimalist dark-slate structural accents over ornamental decoration"_). It distracted from the code quality instead of framing it.

---

### 3️⃣ Rejection Note 2: AI Generated Developer Headshot

- **Prompt Used:** _"Professional corporate portrait of a young software engineer sitting in a modern glass office with a laptop"_
- **Status:** ❌ **REJECTED**
- **Why it was rejected:** The photo had the distinct "AI sheen"—overly smoothed skin, slightly warped background reflections, and unnaturally perfect lighting. It felt dishonest and disconnected from real engineering identity. Replaced with an authentic personal photograph.

---

### 4️⃣ Approved Visual Choice: Minimalist Abstract Banner

- **Prompt Used:** _"Minimalist dark slate grid (#0F172A) with subtle teal glowing line art (#0D9488), low contrast, clean vector style, high resolution, no text"_
- **Status:** ✅ **APPROVED & KEPT**
- **Why it was kept:** Perfectly aligns with the color palette (`#0F172A`, `#0D9488`) defined in `FL-03`, stays quiet in the background, and allows technical code samples and system architecture diagrams to be the loudest element on the page.

---

## 🏆 Summary Rules for Image Curation

1. **Never fake execution:** Work samples (code, DB schemas, pipeline logs) must always be real captures.
2. **Keep style steady:** Any supplemental background AI art must strictly enforce the `#0F172A` / `#0D9488` palette from our brand kit.
3. **Authenticity first:** Human subjects must always be real photos.
